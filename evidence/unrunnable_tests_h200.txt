Both call:

The real API is:
    agent/telemetry.py:300
      def __init__(self, sample_hz=SAMPLE_HZ, output_dir='watchdog_data',
                   gpu_index=None, ...)
    public methods on TelemetryCollector: ['start', 'stop']   -- that is all

Renaming hz -> sample_hz gets past the constructor and then fails on
collector.collect(). These files were written against an API that has never
existed in this repo. They cannot be fixed by a parameter rename; they need
rewriting around start/stop, or around sample_gpu() directly.

flagged that they were broken.
