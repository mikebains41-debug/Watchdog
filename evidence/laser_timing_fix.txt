Reproduce: python3 scripts/repro_laser_timing.py (controlled clock; identical data processed at 1 Hz vs instantly)

D1 real jump, processed at 1 Hz     : none (expect alert)

D1 real jump, processed at 1 Hz     : [11.0] (expect alert)

D3 steady +/-0.5C                   : none (expect none)
D4a normal warm-up 1C/s, at 1 Hz    : none (expect none)
D4b normal warm-up, instantly       : none (expect none)

Before: the verdict depended on how fast the host processed rows. At the real
~1 reading per GPU per second, 3 readings never fit in 0.5s, so a real jump
(D1) was missed; processed instantly, a normal warm-up (D4b) was a false alarm.
After: readings are stamped with when the sample was taken, window 3s, so the
same data gives the same answer at any processing speed.

9/9, test_engines 17/17, multi-GPU contamination audit none.
