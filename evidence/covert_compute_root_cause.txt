The inducer was never the problem. It saturates the GPU completely.

ROOT CAUSE: the detector hook is
    util_pct > 90 AND sm_clock_uniform
sm_clock_uniform is computed in pod_runner.py as
    (max(sm) - min(sm) < 50) if len(sm) > 1 else None
sm_clocks_seen is a DEDUPLICATED set. The SM clock held at exactly
1455 MHz across all 255 samples, so the set has ONE element, so the
len > 1 branch is skipped and uniform returns None. None fails the AND.

The stage therefore fails BECAUSE the clock was perfectly uniform -- the
exact condition it is testing for. Inverted logic, in my own tooling.

FIX: a single distinct clock value over N>1 samples is the STRONGEST
possible evidence of uniformity and must return True, not None. Return
None only when zero samples were collected.
